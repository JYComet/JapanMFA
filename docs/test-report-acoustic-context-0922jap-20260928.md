# 0922jap Qwen 裁剪边界修复复核（2026-09-28）

> 后续停顿合并、跨轨标点同步和句首起音修复已完成，当前发布状态见[统一问题台账](alignment-issues.md)。本报告保留此前的声学上下文修复证据。

## 根因

原生 Qwen ForcedAligner 对 0110 第二句给出 1.92–2.88 秒，而工作 WAV 的第二句强语音约从 1.87 秒持续至 3.21 秒，之后还有尾音衰减。流水线原先把 Qwen 两端当成 MFA 的硬裁剪边界：MFA 无法看到 1.87–1.92 秒的起音和 2.88 秒之后的尾音，于是最终 TextGrid 把后者标成静音。旧质量检查只审计 MFA 明确输出的静音，遗漏了裁剪范围外合成的静音，错误地发布了 0110。

## 修复

Qwen 时间戳继续决定分组和审计锚点。仅当锚点外紧邻至少 50 毫秒、达到本段语音相对强度的连续声能时，MFA 裁剪才延伸到该声音结束后的短静音；扫描范围最多 0.6 秒，且不越过相邻 Qwen 分组的间隙中点。补入的上下文只经过安静帧，遇到另一段声音即停止。`mfa.json` 同时记录原 Qwen 锚点、实际裁剪边界和声学支持范围。超过 0.2 秒的 Qwen/MFA 外边界差异仍记录；只有该方向的差异落在独立声学支持范围内（允许一帧时间分辨率误差），且全部音素、静音和能量检查通过，才允许发布。

另对分段后合成的静音运行持续强声能覆盖检查。阈值以同一条音频已归属的语音强度为参考，避免把 0110 间隙中约 0.02 RMS 的低声背景误认成缺失语音；像旧 0110 尾部约 0.2 RMS、持续 0.3 秒以上的声音则必须被发现。没有拉伸词内音素边界，仍由 MFA 产生边界；原有的显式静音邻接声能修正可将尾元音延至真实声能下降处。

## 0110 真实音频

修正后第二句输入 MFA 的裁剪范围为 1.77–3.33 秒，原 Qwen 锚点仍为 1.92–2.88 秒。MFA 的最后一词 `ない` 原始到 3.10 秒；声能尾部修正后 `/i/` 到 3.29 秒，此后工作 WAV 的 10 毫秒帧中没有 RMS > 0.03 的声音。前一版在 2.88 秒开始标静音，约 0.35 秒的明显语音被漏掉。新 `postprocess.json` 的合成静音覆盖、BGM、短音素和低能量音素问题均为空；Qwen 词尾差 0.22 秒以声学证据支持的差异保留在审计记录中。
