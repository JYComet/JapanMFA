3. 规则可达性：`ッ`+拨音/浊音规则（#325–#340 等）已被 `pʲː`(295)、`tʲː`(58)、

## 优先重跑队列的证据（393 条）

`filtered-retry-20261008/known-filtered-phone-evidence.json` 记录了本轮**定向**重跑的
393 条样本，目标音素分布：


结果：**84 通过 / 309 仍被筛**，被筛原因 362 条是 `no_mappable_pronunciation`。

逐条核对源台本后确认：这些目标是 **CTC 声学侧检测到的假想音素**，源文本里
根本没有对应的假名。例如：

| key | 源文本 | CTC 目标 |
|---|---|---|
| `ALcot_Yomegami/0011955…` | 昨日はありがとうな。おかげで**ぐっすり**眠れたぞ。 | `dzː dʲː` |
| `Bug_System_Sukui_no_Serenade/sn-04a_02-0054…` | また**ギュギュ**締め付けてきた。 | `ɟː` |
| `CUBE_Koi_Suru_Kanojo…/MAY010021…` | 今日は一日ベタベタ**ギュっ**てイチャイチャする予定だよ。 | `ɟː` |
| `CRYSTALiA_RED…/VO20_2138…` | **グラフィティ**…**モロッコ**に行っちゃった。 | `dzː dʲː tʲ ɸʲ` |

文本里是 `っす` / `ギュギュ` / `って` / `フィ` / `ッコ`，**没有** `ッビ` `ッディ`
`ッワー` `ッヒ` `ッギ` `ッフィ` `ッリ` `ッラ` 这类序列。流水线把它们判为
`no_mappable_pronunciation` 是**正确拒绝**（不凭声学猜测编造文本里不存在的音素），
不是漏检。

→ 结论：这 9 个音素在当前语料中"缺失"是**预期且正确的**结果；
若某天台本真的出现 `ッラー`、`カッワーリー` 一类词，map 已能产出。
